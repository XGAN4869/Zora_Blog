# Nuxt3 复现总览

## 文档目的

这套文档用于指导 LLM 分阶段复现当前项目，但复现目标已统一替换为：

- Nuxt 3
- Vue 3
- TypeScript
- Windi CSS

文档不会提供任何实现代码，也不会提供单元测试代码。所有内容都以“任务拆解 + 可直接投喂 LLM 的提示词 + 测试方式”的形式组织，方便你逐步推进。

## 复现目标

需要复现的不是底层框架写法，而是整体产品能力和页面结构。目标站点应具备以下能力：

1. 个人主页首页，包含主视觉、自我介绍、项目展示、GitHub 活跃度展示、氛围化背景效果与格言模块。
2. 全站统一布局，包含导航栏、页脚、亮暗主题切换、SEO 元信息和全局样式系统。
3. 博客系统，支持文章列表、标签筛选、文章详情页、基于内容目录的静态内容管理。
4. 在线简历页，支持版本切换、模块化展示教育背景、技能、项目和经历。
5. 关于页，展示头像、技能栈、工具链、联系方式与个人简介。
6. 占位型扩展页面，用于承接未来功能，例如足迹地图。
7. 评论、图表、内容渲染、性能优化与最终验收体系。

## 推荐执行方式

建议严格按本文档顺序执行，不要让 LLM 一次性生成整个项目。更稳妥的做法是：

1. 每次只给 LLM 一个阶段文档中的一个任务提示词。
2. 等当前任务的手动测试和单元测试规划落实后，再进入下一个任务。
3. 每完成一个文档，就做一次阶段性回归，避免后续返工。
4. 如果 LLM 在某一步引入了额外库或改动了既定目录结构，先停下来核对是否真的有必要，再继续。

## 全局约束

每次给 LLM 下发任务时，都建议追加下面这段通用约束。

> 你正在实现一个 Nuxt 3 + Vue 3 + TypeScript + Windi CSS 的个人站点。请只完成当前任务，不要擅自扩展到未安排的任务。优先保持目录清晰、组件边界明确、数据结构可复用、页面响应式友好。实现完成后，请输出：1）本次新增或修改了哪些文件；2）我应该如何验证功能；3）有哪些风险点或后续建议。不要输出与当前任务无关的额外功能。

## 阶段验收建议

### 第一阶段

完成文档 01 和 02 后，站点至少应能具备：

- 可正常启动和构建
- 存在基础路由壳子
- 拥有统一布局和主题切换
- 页面基础样式正常

### 第二阶段

完成文档 03、04、05 后，站点至少应能具备：

- 首页内容完整
- 博客列表和详情可访问
- 简历页与关于页可访问
- 数据配置能够驱动多个页面

### 第三阶段

完成文档 06 后，站点至少应能具备：

- 关键交互有测试手段
- 性能策略已经落地
- 全站有最终验收清单
- 可以进入部署阶段

## 最后提醒

这套文档的核心不是“让 LLM 直接把页面堆出来”，而是把复现过程拆成稳定、可测试、可回滚的小步前进。只要你坚持每一步都做验证，整体复现成功率会高很多。
